# László Mócsy's Custom Skills

Agent skills by László Mócsy, for Claude Code, Codex, Cursor and [other agents](https://skills.sh).

## Install

```bash
npx skills add LaszloMocsy/skills                        # choose from all skills
npx skills add LaszloMocsy/skills --skill sketch-design  # install one skill
```

## Skills

| Skill | Description |
|---|---|
| [sketch-design](skills/sketch-design/SKILL.md) | Design UI in the Sketch Mac app through Sketch's built-in MCP server: screens, components and design systems built with Frames, Stacks, Color Variables, shared styles and Symbols, with every step checked by screenshot. Requires Sketch 2025.2.4+ with the MCP server enabled ([setup](skills/sketch-design/references/setup.md)). |

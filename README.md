# László Mócsy's Custom Skills

Agent skills by László Mócsy, for Claude Code, Codex, Cursor and [other agents](https://skills.sh).

## Install

```bash
npx skills add LaszloMocsy/skills                        # choose from all skills
npx skills add LaszloMocsy/skills --skill sketch-design  # install one skill
```

## Skills

| Skill | Description |
|---|---|
| [sketch-design](skills/sketch-design/SKILL.md) | Design UI in the Sketch Mac app through Sketch's built-in MCP server: screens, components and design systems built with Frames, Stacks, Sections, Color Variables, shared styles and Components with Variants, with every step checked on the canvas. It can also read and answer Workspace comments. Built and tested for Sketch 2026.4 with the MCP server enabled ([setup](skills/sketch-design/references/setup.md)). |
